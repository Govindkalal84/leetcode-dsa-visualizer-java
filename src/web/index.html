🧮 Theoretical & Mathematical Foundations (Involved Mathesis)

Anagram sirf ek string problem nahi hai—yeh Group Theory (Symmetric Group S_n), Multiset Bijection, Vector Space Invariant in Z^26, aur Fundamental Theorem of Arithmetic par aadharit hai!

1

Zero-Sum Vector Space Invariant (Z^26)

Dono strings ko 26-dimensional integer vector space $\mathbb{Z}^{26}$ mein dekhein. Har character ek basis vector $e_c$ hai:

ΔV = ∑_{i=0}^{n-1} (e_{s1[i]} - e_{s2[i]}) = 0 ∈ ℤ^{26}

Humara count[s1.charAt(i)-'a']++ aur count[s2.charAt(i)-'a']-- single loop mein exact vector subtraction compute karta hai!

2

Pigeonhole Principle & Early Exit

Agar $|s_1| = |s_2| = n$, aur hum $s_1$ ke liye count increment karte hain aur $s_2$ ke liye decrement:

∃ c : count[c] < 0 ⇒ NOT Anagram (Instant Break)

Pigeonhole Principle ke anusar, agar koi count negative ho gaya, toh aage chalkar use balance karne ke liye $s_1$ ke pas utne characters bachenge hi nahi! Isse hum bina second loop ke turant return false kar sakte hain.

3

Fundamental Theorem of Arithmetic (Gödel Prime Hashing)

Interactive Math Lab

26 alphabets ko pehle 26 prime numbers assign karein: a→2, b→3, c→5, d→7, e→11.... Har string ka hash uske letters ke primes ka product hota hai: $H(s) = \prod_{c \in s} P(c)$. Kyunki Prime Factorization Unique hoti hai, do strings tabhi anagram hongi jab unka prime product barabar hoga!

4

Why Bitwise XOR Fails for Anagrams (Counterexample)

Interview Trap Question: "Kya hum LC 136 ki tarah XOR use kar sakte hain?"

s1 = "aa" ➔ 'a' ⊕ 'a' = 0
s2 = "bb" ➔ 'b' ⊕ 'b' = 0
XOR(s1) == XOR(s2) = 0, lekin "aa" != "bb"!

XOR information ko lose kar deta hai (self-inverse property $x \oplus x = 0$). Isliye Frequency Vector strictly zaroori hai!

5

Discrete Translation Mapping (Δ = ord(c) - 97)

ASCII table continuous integer mapping deta hai jisme 'a'=97 se 'z'=122 hain:

f(c) = ord(c) - ord('a') ∈ [0, 25] ⊂ ℤ

Yeh discrete bijection hume contiguous 26-size integer array memory use karne deta hai with $O(1)$ direct hardware memory indexing!
